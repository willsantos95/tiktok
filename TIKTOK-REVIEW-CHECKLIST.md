# TikTok Review Checklist

- [ ] Website opens without login
- [ ] Website is not only a landing page
- [ ] Features and application purpose are clearly explained
- [ ] Privacy Policy is active
- [ ] Terms of Service is active
- [ ] Both legal links are visible on the home page
- [ ] Both legal links are visible in the header and footer
- [ ] Support email is valid
- [ ] All pages work in an anonymous browser window
- [ ] HTTPS is enabled
- [ ] The production domain matches the domain shown in the demo video
- [ ] Test credentials are added to Apply Reason if the real application has login
- [ ] The TikTok verification file is placed in the exact requested path
